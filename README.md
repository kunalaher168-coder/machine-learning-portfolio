# Machine learning portfolio

Public, independently rebuilt work samples based on general skills from private projects. All example records, labels, boxes, and coordinates are invented. No client data, private guidance, original notebook, imagery, model weights, or source archive is published.

Each topic lives on its own branch:

| Branch | Public demonstration |
| --- | --- |
| [ml-classification](https://github.com/kunalaher168-coder/machine-learning-portfolio/tree/ml-classification) | Group-aware training and holdout evaluation on synthetic records |
| [object-detection](https://github.com/kunalaher168-coder/machine-learning-portfolio/tree/object-detection) | Intersection over union and class-aware non-maximum suppression |
| [geospatial-reporting](https://github.com/kunalaher168-coder/machine-learning-portfolio/tree/geospatial-reporting) | Synthetic observation summary, SVG map, and Markdown report |

These examples show approach and code quality. Synthetic test results are not claims about performance on real data.
